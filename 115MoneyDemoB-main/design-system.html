色彩

視覺語彙是「深色拼貼桌面上散落的淺色剪報」：頁面底色深、卡片是牛皮紙色，強調色取自公文的朱印紅與銅印黃。點任一色票可複製 token 名稱。對比度由本頁 JS 即時計算，不是寫死的數字。

介面角色（UI roles）

介面元素一律用這組角色 token，不要直接寫死色碼，也不要借用下方的圖表分類色。對比度徽章是拿該色當文字色去比底色算的——所以底色類的 token （如 --ui-canvas）標成紅字是正常的，它本來就不是拿來寫字用的。

剪報語彙色（newsprint）

--np-* 是兩頁共用同名的一組。*-ondark 結尾的專供直接壓在深色底上的文字使用；淺色卡片內的文字仍用 --np-ink。

圖表分類色（資料語意專用）

這組色帶有資料語意，不可挪作 UI 裝飾用。 --chart-cat-new ／ --chart-cat-extend 的綠與藍是第 2 章甘特圖的政黨色編碼；第 3 章另外獨立出 --chart-cat-ch3-*，就是為了改第 3 章配色時不會牽動政黨色。改任何一個之前先確認它代表什麼。

字體

標題用襯線體（Noto Serif TC）、內文用無襯線體（Noto Sans TC）。字級全部是 clamp() 流體字級，隨視窗寬度連續變化，不設中間斷點。右側的實際值是此刻你這個視窗算出來的結果——縮放視窗會即時變動。

用途 Token Stack
標題／章節大標 --font-display 'Noto Serif TC', 'Songti TC', 'PMingLiU', serif
內文／介面 --font-body 'Noto Sans TC', sans-serif

字級

中文排版另外套了兩條規則：內文用 line-break: strict 做中文斷行禁則（避免行首出現「」）、。」等收尾標點）；內文 line-height 為 1.8、全站 letter-spacing 為 0.03em。

版型與節奏

這個專題是捲動敘事（scrollytelling），所以「版型 token」有一半其實是時間 token：它們決定每一拍佔多少捲動距離。這幾個值只存在於 index.html。

Token 值 作用
--site-header-h 83px 固定頂部導覽列高度。釘住的圖表舞台靠它預留頂部間距，否則圖表標題會被 nav 蓋住。
--chart-stage-gap 24px 舞台內容與 nav 之間的額外呼吸空間。
--chart-stage-clearance calc(header + safe-area + gap + short-extra) 合成值。含 env(safe-area-inset-top)，所以瀏海機／全螢幕手機不會被系統列裁到。
--chart-stage-height calc(100svh - stage-top) 用 svh 而非 vh：手機瀏覽器網址列收合時 vh 會跳動，釘住的舞台會抖。
--scene-read-interval 100svh 一拍的長度。一張故事卡佔一個視窗高的捲動距離。新增的敘事節拍（例如第 2 章結尾那段留給圖片 3 的空白跑道）要對齊這個量級，讀者感受到的節奏才一致。
高度單位一律用 svh，不要用 vh。全站的釘住舞台、跑道、卡片高度都是 svh；混用會在手機上產生只有滾動時才看得到的位移。

動態

緩動曲線一律「快進慢出」（out 系列）——捲動觸發的動畫要立刻有反應，尾段再慢慢收。全站沒有用過 ease-in 或 linear。點按鈕可重播。

時長慣例

時長 用在哪
0.2s – 0.3s hover／focus 等直接回應手部操作的互動
0.4s 卡片進場、文字淡入
0.8s 圖表面板整體切換、甘特圖階段轉場
1s – 1.2s 長條圖的 width 成長——刻意慢，讓數字的變化被看見
長條圖一律動 width ／ height，不要改成 transform: scaleX/scaleY。每根長條都有 border-radius，縮放會把圓角一起拉扁。而且長條只在離散的步驟切換時動，不是每幀重算，改成 transform 也省不到效能。

元件

以下都是實際運作的元件，不是截圖。可以 hover、可以聚焦。

story-card — 剪報卡

紙紋、撕邊、微傾角

三個效果疊起來才成立： paper-texture.png 以 background-blend-mode: multiply 疊在底色上、 clip-path 在底緣切出撕紙邊、 rotate(-0.4deg) 讓卡片像隨手貼上的剪報。滑鼠移上來看看進場狀態。

底色填 #f5efdb 而非目標色 #ebe5d2——紙紋以 multiply 疊上去會把每個通道壓暗約 4%，所以填入值是反推放亮後的結果（ 255 × 目標 ÷ 紙紋均值）。直接填目標色會比旁邊平塗的日期節點暗且偏灰。

按鈕

跳至主要內容
主要按鈕用 --np-seal-red-bright 而非 --ui-accent：暗朱印紅壓在深色頁尾上對比不足，會糊在背景裡。最右邊的 skip-link 平常 top: -100px 藏在畫面外，只有鍵盤 Tab 聚焦時才滑進來。

跨頁 token 對映

兩頁的 token 命名不同，跨頁複製 CSS 會安靜地掉樣式。 CSS 自訂屬性找不到宣告時不會報錯、不會 fallback，整條宣告直接作廢，屬性回到繼承值——版面結構會對、只有顏色掉了，掃一眼很容易放過。搬 CSS 前先把區塊裡所有 var(--…) 抓出來逐一對映。
index.html database.html 實際色值 備註
--ui-muted --np-muted-ondark #A79C8C 同值，不同名
--ui-ink-inverse --np-text-ondark #EDE6D3 同值，不同名
--ui-canvas --bg-color #12191A 同值，不同名
--ui-paper --card-bg #d5cdcd 同值，不同名
--ui-accent --primary-color #A5271E 同值，不同名
--np-* 全系列 --np-* 全系列 — 同名同值，可直接搬
--font-*／ --type-* --font-*／ --type-* — 同名同值，可直接搬
--chart-cat-* （無） — 只有 index 有；database 用自己的圖表色
--site-header-h 等舞台 token （無） — 只有 index 有捲動舞台
寫死的字面值（頁尾底色 #1E1410、分隔線 rgba(237,230,211,…)）跨頁搬是安全的。所以「哪些該用 token、哪些該寫死」在這個多頁專案裡不只是風格問題。

陷阱

每一條都是實際踩過、而且「壞掉的時候看起來不像壞掉」的。完整記錄在 115MoneyDemoB-main/LEARNINGS.md。

# 陷阱 怎麼避開
1 跨頁複製 CSS 導致 var() 找不到宣告，顏色安靜地掉光 先查上面的對映表，逐一對映而不是複製
2 index.html 有一條全域 h2::after 朱印裝飾線，會漏到頁尾等小標題上，和分隔線疊成雙線 新增 h2 時檢查有沒有吃到；需要時用 ::after { display: none } 關掉。 database.html 沒有這條規則，刻意不要加覆蓋
3 第 3 章的 .ch3-color-teal ／ .ch3-color-blue 實際 render 出來是赭紅與紫藕，名稱與顏色相反 名稱是舊配色的殘留。別把 class 名當配色依據，也別「修」回綠藍——那正是需求明確排除的顏色
4 index.html ／ database.html 在根目錄與 115MoneyDemoB-main/ 各有一份，GitHub Pages 從根目錄 build 每次改都是四個檔案。改完用 cmp index.html 115MoneyDemoB-main/index.html 驗證
5 只寫 text-align-last: justify 而沒有 text-align: justify，兩字職稱不會撐開 兩條一起給。單行文字同時是第一行與最後一行，但仍要在 justify 情境下才生效
6 把長條改成 transform: scaleX 想省效能 圓角會被拉扁，而且長條只在離散步驟切換時動，省不到
7 mask-image: url(外部 SVG) 在 file:// 下整個元素不渲染（不是破圖，是完全消失） 需要用 CSS 控色的圖示，把 SVG path 內嵌進 HTML 並用 fill="currentColor"
8 改「更新日期」時只改畫面上的文字 每頁要改三處： <time> 的 datetime 屬性、畫面文字、JSON-LD 的 dateModified。漏掉不會有任何錯誤訊息

維護這一頁

單一事實來源是 index.html / database.html 的 :root，不是這一頁。這頁的 :root 是抄過去的副本，所以動了那兩頁的 token 之後，這頁要跟著更新—— 否則文件會比程式碼更有說服力地說錯話。色票的色值與對比度都是 JS 從實際 computed style 讀出來再算的，所以只要改對了這頁的 :root，展示區與數字會自己跟上。
